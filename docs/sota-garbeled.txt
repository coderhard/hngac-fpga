\section{Zero-Time-Cost Security Dimensionality Expansion}

No prior work explicitly formulates or proves the "zero-time-cost security dimensionality expansion" property for multi-dimensional graph, ABAC, or NGAC policy evaluators. However, structural parallels exist in packet classification hardware and System-on-Chip (SoC) bus protection wrappers, where widening evaluated bit-vectors expands spatial logic area without altering clock cycle latency.   

In bit-vector packet classification architectures (e.g., StrideBV) and hardware access control wrappers (e.g., AKER), expanding evaluated bit-widths increases combinational gate count (LUT usage) while lookup latency remains constant in terms of clock cycles. However, these systems evaluate fixed network packet headers or bus signals rather than variable graph-compiled access policies. 5D H-NGAC establishes this clock-cycle invariance specifically for graph authorization primitives (NGAC/ABAC), contrasting with software implementations where adding attributes increases processing overhead.

\section{Closed-Form Latency Formulations for Hardware Authorization Engines}

Closed-form latency expressions are well-established in deterministic hardware access control units, memory protection units, and network packet filters. Hardware safety mechanisms, such as SECA or hardware firewall pipelines, operate with fixed O(1) cycle bounds or linear pipelined scan bounds dependent on table depth.   

5D H-NGAC provides a precise closed-form expression (L(n)=12+n/2 clock cycles for n rules) specifically for pipelined bitmask policy graph evaluation synthesized via high-level synthesis (HLS). The initiation interval (II=1), absence of early exits, and fixed loop trip counts guarantee zero cycle jitter (min=mean=max), establishing deterministic timing bounds required for real-time cyber-physical systems (CPS).

\section{Synthesis, Ranked Prior Art, and Final Verdicts}

An adversarial reviewer might attempt to challenge 5D H-NGAC by combining software policy compilation techniques (e.g., XEngine) with hardware bus wrappers (e.g., AKER). However, no prior work unifies NIST NGAC graph compilation, multi-dimensional expansion, closed-form deterministic cycle evaluation, and FPGA hardware synthesis into a single primitive.   

\subsection*{Ranked List of Top Five Closest Prior Works}

\begin{enumerate}
\item \textbf{AKER (Restuccia et al., ICCAD 2021):} Hardware Access Control Wrappers (ACWs) on SoC AXI buses. Closest hardware architecture, but operates at the bus level rather than evaluating multi-dimensional ABAC/NGAC policy graphs.
\item \textbf{m-NGAC Patent (NIST, US Patent 11,909,768 B2, 2024):} Embedded NGAC database enforcement via SQL rewriting. Closest NGAC implementation, but relies entirely on software database views without hardware bitmask logic synthesis.
\item \textbf{VLSI Access Control Engine (Journal of Embedded Systems / Energies, 2025):} Custom 65nm CMOS / FPGA access control FSM pipeline. Closest custom hardware access control circuit, but uses fixed state tables rather than compiled NGAC bitmask graphs.
\item \textbf{NEMO / Honeybee (NSF PAR, 2024):} CXL-attached FPGA acceleration of RBAC for vector databases. Closest hardware-accelerated authorization system, but restricted to RBAC database matrix partitioning.
\item \textbf{On the (In)Security of Secure ROS2 (Deng et al., ACM CCS 2022):} Vulnerability analysis of ROS 2 DDS-Security. Closest domain application paper, providing the exact threat model addressed by 5D H-NGAC's provenance and state dimensions.
\end{enumerate}   

\subsection*{Explicit Verdicts on the Seven Kill-Shot Questions}

\begin{description}
\item[Question 1 Verdict (NGAC in Hardware):] \textbf{REFUTED (NO PRIOR ART EXISTS)}. 5D H-NGAC is the first hardware implementation of NIST NGAC (INCITS 565) on FPGA or ASIC logic.
\item[Question 2 Verdict (Zero Cycle Dimensionality Cost):] \textbf{SUPPORTED WITH ADJACENT HARDWARE PATTERNS}. While bit-vector packet classifiers (StrideBV) and AXI bus wrappers (AKER) exhibit constant cycle bounds when bit-widths expand, 5D H-NGAC is the first to prove and measure this property for high-level 5D NGAC graph authorization primitives.
\item[Question 3 Verdict (Closed-Form Latency Formulation):] \textbf{NO DIRECT PRIOR ART}. 5D H-NGAC's exact formulation L(n)=12+n/2 clock cycles with zero jitter (min=mean=max, II=1) is unique for HLS-based policy graph evaluation engines.
\item[Question 4 Verdict (Provenance & State Conditioning in CPS):] \textbf{NO UNIFIED PRIOR ART}. CPS and robotics platforms enforce these dimensions in isolated silos (SecOC for origin authentication, safety PLCs for platform interlocks, DDS-Security for topic access), but none integrate them into a single, real-time hardware ABAC/NGAC primitive.
\item[Question 5 Verdict (Underweighted Venues & Patents):] \textbf{NO DIRECT CONFLICTS}. Sweeps across FPL, FPT, ReConFig, DATE, ASP-DAC, HOST, CHES, TIFS, TDSC, TECS, and patent databases reveal adjacent hardware access controllers (e.g., VLSI FSM pipelines), but no graph bitmask evaluators.
\item[Question 6 Verdict (TCAM, P4, SmartNIC, Zero-Trust Engines):] \textbf{ADJACENT PRIOR ART}. P4 switch tables and TCAM classifiers process multi-field network headers at line rate, and NEMO processes CXL RBAC, but none compile multi-dimensional NGAC graph policies.
\item[Question 7 Verdict (Recent 2024--2026 Advances):] \textbf{NO DIRECT CONFLICTS}. Recent literature (2024--2026) centers on software Attribute-Based Encryption (ABE) and fog computing frameworks (e.g., Fugkeaw et al.), leaving 5D H-NGAC's hardware novelty fully intact.
\end{description}
